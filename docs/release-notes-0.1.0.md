# ii Engine 0.1.0

The first stable ii Engine release brings the ii menu, installation health, community updates, and private setup help into one Windows desktop app.

## Included

- Discord sign-in with a 30-day rotating Windows Credential Manager session.
- Verified stable menu installation using a signed release manifest.
- Owner-approved BepInEx 5.4.23.4 Windows x64 baseline validation.
- Targeted and full repair previews with verified local backups.
- Backup inventory, safety-snapshot restore, and interrupted-operation recovery.
- Steam library discovery and Gorilla Tag launch.
- Announcements, menu status, and release countdowns.
- Admin-only managed menu publishing with preserved release history and member release selection.
- One-click launch that verifies or repairs the selected menu and BepInEx before starting Gorilla Tag.
- Role-aware Developer portal and Beta-only ii Studio placeholder.
- Private iiGPT assistance with the configured daily allowance.
- Local diagnostics export with no automatic upload.
- In-app account deletion and documented retention periods.

## Requirements

- Windows 10 22H2 or Windows 11, 64-bit.
- Steam and Gorilla Tag for installation and launch features.
- Discord membership for online member features.

## Known limits

- Version 0.1.0 uses manual Engine updates.
- The first public candidate is unsigned and may display a Windows SmartScreen warning.
- ii Studio is visible to Beta Engine Users but its tools are coming in a later release.

Review `SHA256SUMS.txt` before installing. Source code, GPL-3.0 license information, the dependency SBOM, and third-party notices accompany the release.
